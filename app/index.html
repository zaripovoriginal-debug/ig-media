Akvent Shorts

Akvent Shorts is a private, single-user publishing tool of Albert Zaripov, a tech blogger about industrial ventilation and air conditioning. It runs on the author's own computer and uploads the author's own short educational videos (3D explainers about fans, cyclones, air conditioners) to the author's own YouTube channel as YouTube Shorts.

Uses YouTube API Services (YouTube Data API v3, videos.insert)

What the tool does

  • Takes a video the author has already approved for publication.
  • Uploads it to the author's channel «Альберт Зарипов» with a title, description and tags written by the author.
  • Marks the video as containing synthetic (AI-generated) media and as not made for kids.

Who can use it

Only the author. There is no public sign-up, no other users and no third-party channels. The tool does not read, store or share any data of other YouTube users.
