Privacy Policy

Last updated: 9 November 2026

Akvent Shorts ("the tool") is a private publishing tool operated by Albert Zaripov (Ufa, Russia, zaripovoriginal@gmail.com) for his own YouTube channel.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Information is processed in accordance with the Google Privacy Policy.

What data the tool accesses

  • OAuth access to the author's own YouTube account with the scopes youtube.upload (to upload videos) and youtube.readonly (to confirm the channel name and the status of uploaded videos).
  • No data of any other YouTube user is accessed, collected or stored.

How data is used and stored

The OAuth token is stored only on the author's own computer in a file readable only by the author's operating-system account. It is used solely to upload the author's own videos. The tool keeps a local log of uploads (date, video ID, link). No data is sold, shared with third parties or used for advertising.

Deletion and revocation

The author can revoke the tool's access at any time at Google Account → Third-party connections and via the Google security settings page. Deleting the local token file removes all stored authorization data immediately; the local upload log can be deleted at any time. Stored API data is not kept longer than 30 days unless refreshed through the API.
